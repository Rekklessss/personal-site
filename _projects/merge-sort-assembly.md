Implemented merge sort for lists of strings in ARM assembly, sorting them lexicographically in ARMSim. The program separates input handling, string comparison, merge logic, and output into assembly modules, with an option to remove duplicates.

This project connects a familiar algorithm to instruction-level implementation: representing strings, comparing them, and coordinating the sorting and input/output routines on a simulated ARM machine.

[View the code and running instructions](https://github.com/Rekklessss/Merge-Sort-In-Assembly).
